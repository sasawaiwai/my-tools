# ココフォリア チャットアイコン拡大

ココフォリア（ccfolia.com）の「ルームチャット」に表示される発言者アイコンだけを拡大する Chrome 拡張です。

## サイズ
- 標準：ココフォリア本来の表示
- 64px
- 80px（初期値）
- 100px
- 120px
- 160px
- 200px

ポップアップ上部の「標準 ⇄ 80px」で、ログを一気に遡りたい時と表情差分を見たい時をすばやく切り替えられます。

## インストール方法
1. ZIPを解凍する
2. Chromeで `chrome://extensions/` を開く
3. 右上の「デベロッパー モード」をON
4. 「パッケージ化されていない拡張機能を読み込む」を押す
5. 解凍した `ccfolia-chat-avatar-size` フォルダを選ぶ
6. ココフォリアを再読み込みする

## 使い方
Chrome右上の拡張機能一覧から「ココフォリア チャットアイコン拡大」を固定しておくと便利です。
アイコンをクリックし、サイズを選択してください。最後に選んだサイズは保存されます。

## 対象範囲
CSSセレクタは `ul[aria-label="ルームチャット"]` 配下だけを対象にしているため、
盤面のキャラクター画像、ステータス欄、発言入力欄のアイコンには適用しません。

## 注意
ココフォリア側のHTML構造が将来大きく変更された場合、動かなくなる可能性があります。
その場合は content.js のCSSセレクタを調整してください。
